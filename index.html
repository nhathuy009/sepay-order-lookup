Kéo thả file Excel vào đây hoặc chạm / bấm để chọn file
Hỗ trợ .xlsx, .xls — xử lý tự động sau khi chọn
Hệ thống sẽ tự động lọc BAG NO, cộng dồn QTITY, lấy KGS đầu tiên, và đọc ô B5 của mỗi sheet để ghi phân loại hàng hóa (bỏ trống nếu là "Kurung"). Kết quả sẽ hiển thị bên dưới để bạn kiểm tra trước khi tải file Excel.
